# Demo Transcript

1. Start the app:

```bash
python -m flask --app app.main run
```

2. Open `http://127.0.0.1:5000/crawl`.

3. Enter a small documentation site or personal site as the seed URL.

4. Use depth `1` and max pages `10` for a quick demo.

5. Return to the homepage and search for a topic that appears on the crawled site.

6. Point out that every result shows lexical relevance, graph authority, and the combined final score.
